# Newton Crash Explorer POC

A static, browsable map of reported Newton, Massachusetts crashes from 2016 through 2026 year to date. Includes colored ward and precinct views and clickable crash details.

Data comes from MassDOT IMPACT and MassGIS. Snapshot downloaded November 4, 2026. The 2026 dataset contains 1,421 available records; its latest crash date is October 28, 2026. Recent years are provisional.

This repository contains the published browser assets. GitHub Pages publishes the main branch root. No build step is needed. Keep .nojekyll so assets are served without a Jekyll build.

The source data and preparation scripts remain in the local Newton crash data project. This hosting migration changes the URL, not the app's functions or data.
